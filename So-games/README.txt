Só GAMES - PROJETO ACADÊMICO

Estrutura:
- index.html = página principal/home
- login.html = tela de login e cadastro
- css/estilo.css = estilos, layout e media queries
- js/script.js = JavaScript e validação dos formulários
- js/jquery-script.js = funcionalidades com jQuery

Tecnologias utilizadas:
HTML5, CSS3, Bootstrap 5.2.2, Media Query, JavaScript e jQuery.

Observação: o login/cadastro é uma demonstração de interface e validação no navegador; não há banco de dados.
